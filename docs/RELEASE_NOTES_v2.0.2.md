# Love v2.0.2 — «Voice that connects.» 🖤

> RU ниже ⬇️

## 🔧 What's fixed

- 🎙️ **Voice & screen-share now connect reliably** — added a dedicated self-hosted TURN relay, so DM calls and server screen-share establish even behind strict NAT/firewalls (no more failed connections).
- ✅ **Sign-up fixed** — typing your username no longer bounces you to login; registration goes through.
- ✉️ **Emails via Resend, redesigned** — verification codes and password resets now deliver reliably with a refreshed premium look.
- 💬 **Start a DM from Friends / profile** — opens (and creates) the conversation right away.
- 🔑 **Password recovery** — request a code by email and set a new password.
- 🤖 **Android build restored** — fixed CI toolchain (Node 22 + Java 21).
