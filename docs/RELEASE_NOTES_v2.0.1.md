# Love v2.0.1 — «Smoother onboarding.» 🖤

> RU ниже ⬇️

## 🔧 What's fixed

A focused stability update — getting in and starting conversations is now seamless.

- ✅ **Sign-up fixed** — typing your desired username no longer kicks you back to the login screen, and account creation goes through cleanly.
- ⚡ **Faster, friendlier errors** — the server never hangs on email delivery: if the mail can't be sent, you get a clear message instantly instead of a frozen screen.
- 💬 **Start a DM from Friends** — tapping the chat button on a friend (or "Message" on their profile) now opens — and creates if needed — a direct conversation right away. No more "only servers work".
- 🔑 **Password recovery** — request a reset code by email and set a new password, end to end.
- 🤖 **Android build restored** — fixed the CI toolchain (Node 22) so the APK builds and ships again.

## 🔧 Что исправлено (RU)

Точечное обновление стабильности — вход и начало общения теперь без заминок.

- ✅ **Починена регистрация** — ввод желаемого никнейма больше не выкидывает обратно на экран входа, а создание аккаунта проходит без сбоев.
- ⚡ **Быстрые, понятные ошибки** — сервер больше не зависает на отправке письма: если письмо не уходит, вы сразу получаете внятное сообщение вместо «замёрзшего» экрана.
- 💬 **Личный чат прямо из «Друзей»** — кнопка чата у друга (и «Написать сообщение» в его профиле) теперь сразу открывает — и создаёт при необходимости — личную беседу. Больше не «работает только через серверы».
- 🔑 **Восстановление пароля** — запросите код на почту и задайте новый пароль, полный цикл.
- 🤖 **Android-сборка восстановлена** — починен CI (Node 22), APK снова собирается и публикуется.
