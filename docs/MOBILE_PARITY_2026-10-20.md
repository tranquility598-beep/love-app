# Love: перенос изменений ПК на Android

## Что перенесено

| Область | Android |
|---|---|
| Заблокированные | Настройки → Конфиденциальность: список, обновление, разблокировка только своего блока; дружба автоматически не возвращается |
| Настройки | Поиск под заголовком, выход с подтверждением; мобильная навигация использует штатные Flutter-компоненты |
| Публичная страница | В профиле настроек — состояние страницы, копирование ссылки, редактор в браузере через одноразовый код |
| Обращения | Общая серверная политика: одно открытое ручное обращение, затем 15 минут паузы; причина и таймер в поддержке и формах Hub; старый backend блокирует новые отправки |
| Вложения | До пяти файлов в вопросах/багах/идеях; проверка формата и размера, удаление из черновика, повтор без повторной загрузки успешных вложений |
| Голос/ЛС | Общая очередь SDP и раннего ICE, согласованная с ПК обработка встречных offer; поздний ICE-конфиг применяется к существующим соединениям |
| Аудио/видео | Аудио и видео разных потоков ПК собираются для мобильного рендерера; учитываются раннее media_state, громкость 0 и поздний результат разрешения/захвата |
| Выход из войса | Состав, потоки и соединения отсоединяются до асинхронного закрытия; своя плитка исчезает сразу, старые callbacks не оживляют звонок |
| Экран звонка | ЛС и комнаты используют общий CallScreen; действия блокируются до подключения и во время запроса медиа, демонстрация показывается целиком |
| Ссылка «Написать в Love» | Точный поиск username с учётом блокировок; ожидание входа без повторного тоста, защита от двойного открытия и смены аккаунта |
| Сохранение профиля | Мгновенная блокировка повторного сохранения; поздний ответ профиля/аватара/музыки не меняет другой аккаунт |

## Уже было в мобильной версии

Сохранены OTP/регистрация, Soft v3, Halloween с возвратом к обычной теме,
подписки без оплаты, жалобы на профиль/сообщения и ответы поддержки.
Короткие сообщения настроек показываются через SnackBar и не записываются
в серверную историю. Публичная страница и эффекты используют общий HTML/CSS/JS
с ПК; отдельной расходящейся Flutter-копии страницы нет.

## Проверки и ограничения

- `dart analyze lib`: без замечаний на финальном исходнике.
- `node --check`: API, init-app, script, Electron main и users route — успешно.
- Android debug APK: `2.2.0-preview`, build 5, API `http://127.0.0.1:5555`.
- Debug устанавливается отдельно: `chat.loveapp.mobile.preview`, «Love Preview».
  Подпись установленной 2.1.1 отличается: обновление поверх было отклонено
  Android, исходная Love и её данные сохранены. В Preview нужно войти отдельно.
- Для локального прогона нужен подключённый USB и `adb reverse tcp:5555 tcp:5555`.
- Основные версии проекта остались 2.1.1; номер будущего релиза 2.2.0 предложен владельцу.
- Автотесты, реальные обращения, звонки/камера/захват двумя клиентами агентом не запускались.
- Требуется ручной прогон владельца: звук в обе стороны, камера и демонстрация
  ПК ↔ телефон, выход/повторный вход, ссылка на профиль, поддержка и блокировки.
- TURN локально не настроен; соединение через разные ограничивающие сети
  пока не гарантировано. FCM и production-подпись APK требуют отдельной настройки.
- Production и Actions не запускались. Обновление серверных зависимостей
  по прежнему ждёт отдельного разрешения; прежний audit-блокер CI остаётся открытым.
