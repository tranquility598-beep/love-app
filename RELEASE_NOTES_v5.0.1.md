🚀 Love App v5.0.1 — Плавные переходы

Обновление с улучшениями UX при загрузке приложения.

✨ Нововведения

🌈 Плавные fade-переходы при загрузке: Больше никаких резких пропаданий экрана загрузки! Теперь приложение плавно исчезает, создавая приятный визуальный опыт.

📊 Прогресс-бар при холодном старте: Если сервер ещё не прогрелся (например после деплоя), вы увидите индикатор прогресса и статус-сообщения:
- «Подождите немного...»
- «Это занимает чуть дольше обычного...»

🔄 Мягкий сброс при ошибке авторизации: При истечении сессии приложение мягко вернёт на экран входа — без бесконечных перезагрузок.

🛠 Под капотом

- Переработана логика скрытия loading-screen: теперь используется opacity + transition вместо display:none
- Добавлен window.testWarmupUI() для отладки в DevTools
- Progress bar и статус-строка интегрированы в loading-screen
