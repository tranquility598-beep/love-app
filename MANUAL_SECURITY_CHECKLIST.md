## 🛡️ Проверка CSP

### Текущий CSP (client/main.js:490):
```javascript
"script-src 'self' 'unsafe-inline' 'unsafe-eval';"
"style-src 'self' 'unsafe-inline';"
```

### Проблемы:
- ❌ `'unsafe-inline'` для scripts - позволяет inline onclick
- ❌ `'unsafe-eval'` - требуется для DOMPurify
- ❌ `'unsafe-inline'` для styles - позволяет inline стили

### Количество inline обработчиков:
```bash
# Подсчитать onclick в HTML:
grep -o "onclick=" client/index.html | wc -l
# Результат: 123+
```

### План миграции:
1. [ ] Мигрировать все onclick на addEventListener
2. [ ] Проверить необходимость DOMPurify (можно ли заменить?)
3. [ ] Убрать unsafe-inline для styles
4. [ ] Включить строгий CSP
