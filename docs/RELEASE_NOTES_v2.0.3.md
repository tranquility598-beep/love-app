# Love v2.0.3 — «Always up to date.» 🖤

> RU ниже ⬇️

## ✨ What's new

- ⬇️ **Automatic updates** — the app now updates itself: new versions download in the background and install on restart. No more manual reinstalls.
- ⚙️ **Updates in Settings** — a real **Settings → Updates** section: current version, status, download progress, and a **"Restart & install"** button. Plus "Check for updates" in-app and in the tray.
- 🧪 **Beta channel** — opt into **"Receive beta versions"** to get pre-releases early (may be less stable). Off by default.
- 🎵 **Profile music fix** — MP3 tracks now actually play for your friends (the cloud copy used to silently fail for larger files).

## ✨ Что нового (RU)

- ⬇️ **Авто-обновления** — приложение обновляется само: новые версии качаются в фоне и ставятся при перезапуске. Больше не нужно переустанавливать вручную.
- ⚙️ **Обновления в настройках** — настоящий раздел **Настройки → Обновления**: текущая версия, статус, прогресс загрузки и кнопка **«Перезапустить и установить»**. Плюс «Проверить обновления» в приложении и в трее.
- 🧪 **Канал Beta** — тумблер **«Получать бета-версии»**: предрелизы раньше всех (могут быть менее стабильны). По умолчанию выключен.
- 🎵 **Фикс музыки профиля** — MP3-треки теперь реально слышны друзьям (раньше облачная копия молча не загружалась для файлов покрупнее).
