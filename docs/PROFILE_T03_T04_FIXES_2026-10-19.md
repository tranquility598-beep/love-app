# Публичный профиль: исправления T03/T04

19 октября 2026. Локальные исправления замечаний PEER-0012.

## Поведение

- Шлейф прерывается при выходе указателя из окна. При возвращении рядом
  с последней точкой новый след не соединяется со старым диагональю.
  Публичная страница слушает невсплывающий `pointerleave` на `documentElement`,
  превью — на своём shadow host. Подсветка тоже гаснет, её ожидающий кадр снимается.
- Жалоба показывает успех только после HTTP 2xx. При сетевом сбое или
  HTTP 400/429/500 форма остаётся открытой, текст сохраняется и доступен повтор.
  Пока запрос идёт, повторная отправка блокируется. Открытие формы заново
  отменяет таймер закрытия от предыдущей успешной отправки.
- Некорректное затемнение фона даёт значение по умолчанию 40%; `0` сохраняется,
  допустимые значения ограничены 0–85%. В CSS больше не попадает `NaN`.
- Публичный рендер повторно проверяет ссылки из старых/импортированных данных:
  только абсолютные HTTP(S). Неправильные записи удаляются перед применением
  лимита тарифа, валидные адреса нормализуются.

  48 вариантов публичных страниц (3 раскладки × 4 набора данных × 4 ширины),
  6 сравнений публичной страницы с превью, lifecycle музыки/эффектов,
  реальные trusted pointerleave Chromium через ввод CDP, форма жалобы,
  затемнение и ссылки, MIME/CSP/host guard. Ошибок renderer нет, записей в БД нет.
- Скриншоты мобильного Focus и настольного Studio просмотрены.

Harness использует настоящий публичный роутер и серверный рендер. Данные
профиля и endpoint жалоб изолированы: отправки жалоб проверяют UI и HTTP,
не создают настоящие обращения. БД, production и физические Safari/iOS/Android
в этом прогоне не использовались. Отчёт — `.tmp-profile-pages/report.json`.

Чтобы увидеть изменения серверного рендера в dev, перезапустите `npm start`:
CommonJS-модули не обновляются от одного refresh страницы. В редакторе
обновите страницу с очисткой кеша. Выкладка остаётся отдельным этапом.
