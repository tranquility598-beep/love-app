🚀 Love App v5.0 — Эра комнат и стабильности

Самое крупное обновление со времён 4.0! Добавили долгожданные комнаты для уютного общения и значительно повысили стабильность приложения под нагрузкой.

✨ Главные нововведения

🏠 Комнаты (Rooms): Создавайте личные голосовые и текстовые комнаты на лету! Идеально для созвонов с друзьями без необходимости поднимать целый сервер. Приглашайте по ссылке — и комната готова.

🎙 Стабильные голосовые звонки: Полностью пересмотрели обработку WebRTC. Теперь:
- Звонок не ломается после переподключения к сети
- Корректно слышно всех собеседников
- Демонстрация экрана видна всем участникам
- Speaker detection работает чётко

🔓 Плавный выход из сессии: Больше никаких бесконечных перезагрузок, если истёк токен! Приложение мягко возвращает на экран входа без потери состояния.

➕ Меню "+" на server-rail: Теперь меню создания сервера/комнаты раскрывается вверх и всегда видно целиком — никаких обрезанных кнопок внизу экрана.

🛠 Под капотом (Технические изменения)

🛡 Расширенный аудит безопасности: Полный пересмотр модели угроз, отчёты SECURITY_AUDIT_REPORT.md и MANUAL_SECURITY_CHECKLIST.md в репозитории. Закрыты потенциальные векторы для XSS и инъекций.

🚫 Антиспам нового поколения: Усиленные фильтры на стороне сервера, защита от флуда сообщениями и реакциями, умные лимиты по контексту.

🌐 Корректный rate limiter для IPv6: Исправили проблему, где IPv6-клиенты могли обходить лимиты. Теперь используется helper ipKeyGenerator из express-rate-limit.

⚡ Прогрев сервера при старте: Сервер теперь готов принимать запросы значительно быстрее после запуска, plus headroom-запас для пиков нагрузки.

🔓 Unlock-on-reset: При сбросе соединения корректно снимаются все блокировки голосового канала — больше никаких «застрявших» залоченных микрофонов.

📦 Отказ от Docker в пользу простоты: Убрали Dockerfile и docker-compose в пользу прямого деплоя — проще ставить, проще обновлять, меньше слоёв абстракции.

📥 Как обновиться?

Просто скачайте установочный файл для вашей системы ниже в разделе Assets:

- Для Windows: Запустите Love Setup 5.0.0.exe
- Для macOS: Запустите Love-5.0.0.dmg (универсальный — для Intel и Apple Silicon M1/M2/M3)

Спасибо, что остаётесь с нами! ❤️
