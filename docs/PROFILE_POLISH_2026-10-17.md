# Профиль и редактор: локальные изменения 17 октября

## Сохранение настроек

- Кнопки сразу показывают «Сохраняем…», повторное нажатие блокируется.
- При медленном ответе появляется пояснение; введённые данные остаются в форме.
- Новые правки во время запроса не затираются ответом сервера.
- Ошибка загрузки аватара прерывает сохранение и сохраняет выбранный файл.
- Сетевой сбой при PUT профиля допускает один повтор с тем же содержимым.
- Сервер валидирует имя, описание и статус; удаление аватара принимает null.

## Редактор и публичная страница

- Монохромное оформление, компактная навигация, согласованные поля и кнопки.
- Превью телефона и масштабируемое десктопное превью шириной 960px.
- Общий движок эффектов: `profile-page/build/effects.js`.
- Музыка в превью после клика, регулировка громкости и прогресс трека.
- Эффект «нет» не запускает частицы; повторный вход не создаёт второй слой.
- При смене эффекта освобождаются кадры анимации, слушатели и наблюдатели.
- Улучшены карточка профиля, ссылки, баннер, экран входа и плеер.

## Ошибка MIME

Запущенный старый backend не знал добавленный динамический маршрут
`/build/effects.js` и отдавал HTML. Движок перенесён в обычную статику;
сервер и браузер используют один файл. Локальный запущенный сервер отдаёт
его с HTTP 200 и `application/javascript`. Для отсутствующих файлов редактора
маршрут теперь возвращает 404 вместо HTML. В desktop-упаковку добавлена
папка редактора, необходимая и серверному рендеру.

## Проверки и ограничения

До переноса движка в статический файл прошли 51 серверная проверка и
изолированная проверка интерфейса на локальных данных: мобильная и десктопная
вёрстка, эффекты, музыка, сохранение черновика и ошибка аватара.
После переноса прошли 5 проверок движка и проверен фактический HTTP MIME
локального сервера. Повторный полный UI-прогон после переноса не завершился.

Команды для дальнейшей проверки по запросу:

```powershell
npm run test:server
node node_modules/electron/cli.js tools/check-profile-ui.cjs
```

Изменения локальные. Для серверной логики нужен перезапуск backend;
для Electron main — перезапуск приложения. Для статического effects.js
достаточно обновить вкладку редактора. В production изменения не опубликованы.

## Предварительный раздел подписок

В настройках добавлен раздел «Подписки» с отображением текущего тарифа
из аккаунта и срока действия. Просроченный платный тариф отображается как Free.
Предварительные месячные цены: Free — 0 ₽, Pro — 299 ₽, Premium — 499 ₽,
Duo — 799 ₽ за два аккаунта (18.10.2026 владелец несколько раз попросил поднять;
были 149 / 299 / 449 ₽). Цены и состав помечены предварительными.

Все кнопки покупки отключены, платёжных запросов, выдачи тарифов и списаний
нет. Экран не требует изменений MongoDB или перехода на PostgreSQL.
Возможности карточек сверены с текущей матрицей `profileTiers.js`;
перед запуском оплаты цены и наполнение нужно утвердить.
