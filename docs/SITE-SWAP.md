# Как поставить новый дизайн сайта вместо текущего

Новый дизайн лежит в папке `opus5-site-mock/`. Боевой сайт — это папка `site/`.
Всё, что нужно: заменить содержимое `site/` файлами из макета и запушить в `main`.

## Коротко: две команды

```bash
bash ops/swap-site.sh
```

Скрипт сам сделает резервную копию старого сайта (положит рядом с проектом,
папка `love-site-backup-<дата>`), пересоберёт `site/` из макета и покажет, что
получилось. Ничего не коммитит — сначала посмотрите.

Посмотреть локально:

```bash
python -m http.server 4173 --directory site
```

Открыть `http://localhost:4173`. Пройдитесь по страницам: главная, скачивание,
поддержка, идеи, история обновлений.

Если всё нравится:

```bash
git add -A site && git commit -m "feat(site): новый дизайн" && git push origin main
```

Сайт живёт на Render (статика из папки `site`, ветка `main`), поэтому после
пуша он переедет на новый дизайн сам, минуты через две. В панель Render
заходить не надо — ничего там менять не нужно, папка та же.

## Что именно меняется

Переезжают 13 файлов: 6 страниц (`index`, `support`, `ideas`, `changelog`,
`privacy`, `terms`), 3 стиля (`core.css`, `land.css`, `doc.css`) и 4 скрипта
(`lang.js`, `community.js`, `depth.js`, `hero-webgl.js`).

Набор страниц тот же, что сейчас, — ни одна ссылка снаружи не сломается.

Два файла отличаются от старого сайта:

- `core.css`, `land.css`, `depth.js`, `hero-webgl.js` — новые, их раньше не было;
- `community.css` — больше не нужен, его стили теперь внутри `doc.css`. Поэтому
  папка пересобирается с нуля, а не копируется сверху: иначе лишний файл остался
  бы лежать на боевом сайте.

Скриншоты дизайна (`d1-hero.png`, `m1-hero.png` и остальные 13) в сайт не
попадают — они нужны были только пока макет рисовался.

## Что уже работает в новом дизайне

- **Поддержка.** Форма на `support.html` отправляет обращение на
  `https://api.loveapp.chat/api/support`, в ответ показывает номер обращения.
  Если сервер не ответил — форма не закрывается, текст остаётся, видно ошибку.
- **Идеи.** Страница `ideas.html` тянет реальные идеи из
  `https://api.loveapp.chat/api/community/ideas` — поиск, сортировка, страницы.
- **Скачивание.** Все кнопки ведут на наш бэкенд:
  `https://api.loveapp.chat/api/updates/download/{win,mac-arm64,mac-x64,android}`.
  Бэкенд сам берёт свежий релиз с GitHub и отдаёт файл с правильным именем.
  Раньше ссылку собирал браузер через `api.github.com`, а там лимит 60 запросов
  в час на IP — у мобильных операторов IP общий, лимит вечно исчерпан, поэтому
  на телефоне и выкидывало на страницу GitHub вместо скачивания. Теперь этого
  запроса нет вообще.
- **Версия.** Номер под кнопками подтягивается из
  `https://api.loveapp.chat/api/updates/version`. Не ответил — останется
  значение из разметки (сейчас `2.1.0`), скачивание от этого не зависит.
- **История обновлений.** `changelog.html` — все девять выпусков от 2.0.0 до
  2.1.0, на русском и английском.

## Если что-то пойдёт не так

Вернуть старый сайт:

```bash
git checkout HEAD~1 -- site && git commit -m "revert(site): вернул прежний дизайн" && git push origin main
```

Или просто скопировать обратно из папки `love-site-backup-<дата>`, которую
сделал скрипт.
